# Repository classes

Classes are declared in `catalog/repository-classes.yaml` and assigned in `catalog/repositories.yaml`. Organization rulesets target `mindclade_repository_class`, so a newly cataloged control repository inherits its policy without a repository-name edit. Changes to class values are security changes.
